HOSPITAL MANAGEMENT - VERSION BASED ON YOUR TEACHER'S SLIDES

1. Extract the ZIP completely.
2. Open the HospitalManagement_Slides folder.
3. Double-click HospitalManagement.sln.
4. In Visual Studio, press Ctrl + F5.

Project type: Console App (.NET Framework).
Target framework: .NET Framework 4.8.
No NuGet packages or database setup are required.
If Visual Studio asks for the .NET Framework 4.8 targeting/developer pack,
install that component using Visual Studio Installer.
